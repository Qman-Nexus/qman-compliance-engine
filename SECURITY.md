# Security Policy

## Supported Versions

The latest development version is supported.

## Security Principles

- Least privilege
- Separation of trust domains
- Short-lived access tokens
- Secure credential storage
- Explicit risk acceptance
- Fail-safe compliance evaluation

## Credential Management

Never commit private keys, access tokens or
operational configuration to source control.

## Reporting a Vulnerability

Please report vulnerabilities privately using
GitHub Private Vulnerability Reporting when enabled.

Do not disclose credentials or sensitive operational
information in public issues.

## Security Limitations

Compliance results reflect the implemented controls
and available data at the time of evaluation.

A successful compliance report does not guarantee
that an environment is secure.
